#Snake and Ladder Game 🎲🐍🪜

Snake and Ladder is a Python-based implementation of the classic board game, where players roll dice and move across a 100-square board, navigating snakes and ladders along the way. This simple yet fun game allows multiple players to compete in real-time to reach the 100th square.

Features:
Multi-Player Support: Supports multiple players with customizable player count.
Ladders and Snakes: Players can climb ladders to advance faster or fall down snakes to lose progress.
Dice Rolling: Players roll a 6-sided dice to move across the board.
Interactive Gameplay: Players take turns rolling the dice and moving their pieces.
Win Condition: The first player to reach square 100 wins the game.
How It Works:
The game initializes with a board having predefined snakes and ladders.
Players take turns rolling a dice (1-6) to move forward.
If a player lands on a ladder, they move up; if they land on a snake, they move down.
The game continues until one player reaches the 100th square.
Technologies Used:
Python: Programming language for the game logic.
Random Module: Used to simulate dice rolls.
Time Module: Used to create a short delay between actions for a better gaming experience.
How to Play:
Clone the repository.
Run the snack_ladder.py file in a Python environment.
Input the number of players and start the game.
Players take turns to roll the dice and move their piece.
The first player to reach the 100th square wins!
